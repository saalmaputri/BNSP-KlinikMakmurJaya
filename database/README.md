# Database

Folder ini berisi seluruh artefak database untuk **Sistem E-Commerce Penjualan Obat Klinik Makmur Jaya**.

File di folder ini:

- [Rancangan Database](./database-design.md)
- [DDL PostgreSQL](./database-schema.sql)
- [Query Laporan dan FIFO](./database-queries.sql)
- [Data Dummy Testing](./database-dummy-data.sql)
- [ERD Database](./erd-database-mermaid.md)

Cara pakai:

1. Baca [Rancangan Database](./database-design.md) untuk memahami relasi, status, dan aturan bisnis yang dipakai.
2. Pakai [DDL PostgreSQL](./database-schema.sql) untuk membuat tabel database.
3. Jalankan [Query Laporan dan FIFO](./database-queries.sql) bila perlu memeriksa query analitik atau stok.
4. Gunakan [Data Dummy Testing](./database-dummy-data.sql) untuk seed data lokal.
5. Buka [ERD Database](./erd-database-mermaid.md) untuk melihat relasi antar tabel.
